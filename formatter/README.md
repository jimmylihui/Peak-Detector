# Formatter

Dataset formatter scripts copied only from `project-BCG-LLM/combined_data/formatter`.

Each formatter is placed beside its target dataset:

| Dataset | Formatter |
| --- | --- |
| MIT-BIH ECG | `ECG/MITBIH/MITBIH_formatter.py` |
| INCART ECG | `ECG/Incart/incart_formatter.py` |
| BIDMC PPG | `PPG/BIDMC/BIDMC_formatter.py` |
| CapnoBase PPG | `PPG/CapnoBase/capnobase_formatter.py` |
| Kansas BCG | `BCG/Kansas/kansas_formatter.py` |
| BCG Arrhythmia | `BCG/Arrhythmia/arrhy_formatter.py` |
| ICU BSG | `BSG/ICU/ICUBSG_formatter.py` |
| Hospital BSG | `BSG/Hospital/BSG_formatter.py` |

Generated formatted datasets, notebooks, plots, arrays, caches, and variant/noise/cross-modality formatter scripts are excluded.
